## What changed

Opening ChatGPT, Claude, or another website does not connect this app. Automatic replies need either:

1. Settings → Local AI → download Qwen after confirmation, then ask a question, or
2. Settings → Gemini → paste a free-project API key → Connect → Google billing check → Ready after a real test reply.

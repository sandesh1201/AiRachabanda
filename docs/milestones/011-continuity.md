# Milestone 011 continuity

A discussion does not depend on one provider. An unavailable participant's unfinished task can move to another eligible participant. The previous session, completed claims, and request budget stay in place.

Pause, resume, stop, finish now, and skip for this discussion are on the Council screen. Skip does not change the provider account. Assisted work stays waiting for the user.

The ongoing notification uses a special-use foreground service while the user has allowed notifications. WorkManager is not used. Android can end the process after a force stop or reboot, and the app does not start the discussion again by itself. The lock-screen text does not include the question.

Room schema version 9 keeps existing conversations through `Migrations.MIGRATION_8_9`.

These items stay for a later milestone:

- Unicode PDF font support.
- Microsoft Office visual compatibility.
- Editable chart improvements.
- OCR and live vision.
- Broader research coverage.
- Research security audit.
- Live AI provider configuration.
- Real multi-model accuracy benchmarking.

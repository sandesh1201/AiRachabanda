# Milestone 015B

Provider setup asks for an API key or the official sign-in, then Connect. Certificate fingerprints, project billing, and model identifiers stay under Advanced details.

Connect stores a key in Android Keystore and does not send a provider request. Ready is shown only when the existing free-access checks have already passed. Groq, Cloudflare, and OpenRouter can save a credential and still stay out of automated Council use.

A developer-owned Android OAuth client can let end users authorize their own Google accounts. Registering that client requires the owner's Google Cloud project and this app's signing certificate. No client secret is stored in the app. That registration was not completed in this pass.

No account was created and no live inference was sent.
